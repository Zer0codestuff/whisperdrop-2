A short guide now opens on first launch, the app uses one spoken language everywhere, and dictated text is cleaner.

## Changes

- New six-step guide: dictation, notes, files and YouTube, model and language, then permissions. It appears once, for new installs and for people updating from earlier versions. Reopen it from Help, WhisperDrop 2 Guide, or Settings, Permissions.
- One spoken language for files, dictation and notes. Change it in the main window, the menu bar or Settings, General. Your earlier choice is kept. Note language, beside New note, now applies to the next note only.
- Dictation no longer capitalizes words in the middle of a sentence after a pause. Short dictation is decoded as one passage, and longer dictation fixes capitals where passages join. Add names to Vocabulary to keep their capitals.
- Dictation that repeats the same phrase back to back is transcribed once more with the full audio window. The new text is used only when it repeats less and keeps the rest of what you said.
- The About panel no longer lists the original project. The README and NOTICE still credit it.

Turbo Q5 remains the default. Transcription runs locally. Dictation, notes, file imports, YouTube videos and playlists remain available.

## Validation and limits

82 automated tests passed in debug and release. Four optional tests that need local models or fixtures were skipped in the standard run. Three synthetic Italian clips of 21, 23 and 34 seconds went through the app's dictation path with Turbo Q5. The two short clips came back as one passage each, with correct punctuation and capitals, and one word was spelled correctly that the previous settings got wrong. The long clip joined cleanly. Latency matched the previous settings. These synthetic clips do not measure accuracy on real speech. The loop retry was tested with sample text only, because a real loop could not be reproduced on demand. In dictation longer than 28 seconds, a name said only once right after a pause can lose its capital unless it is in Vocabulary.

The bundled runtime tools are identical to those in 2.2.0.

## Install

Apple Silicon, macOS 14 or later. Download the DMG, quit the old version, and copy WhisperDrop 2.app into Applications, replacing the previous copy. Models, notes and settings survive replacement.

This release has a local code signature and is **not notarized**. Gatekeeper may block the first launch after a browser download. If you choose to trust this build, try opening it once and follow [Apple's Open Anyway instructions](https://support.apple.com/en-us/102445) in System Settings, Privacy & Security.

SHA256SUMS.txt contains release-asset checksums. FFmpeg-8.1.2-source.tar.xz contains the unmodified FFmpeg source used for this build; its configuration is in scripts/prepare-runtime.sh. Runtime license notices are bundled in the app and documented in the repository.
