# WhisperDrop for Linux

GTK 4 and libadwaita app in Python (PyGObject), the Linux counterpart of the macOS app in the repository root. Follow the root AGENTS.md for product rules, writing style and the "Do not" list; this file adds what is specific to Linux.

## Architecture
- `whisperdrop/core/` is pure Python and mirrors `Sources/WhisperDropCore`: transcript output (`transcript.py`), hallucination and repetition filters and speaker merging (`cleanup.py`), `LiveText` (`livetext.py`), pause-aligned windows, `RollingAudio`, `SentenceParagraphs` and the Whisper note chunker (`audio.py`), and the model catalog (`models.py`). When a rule changes on one platform, change the other and its tests.
- `engine/host.py` keeps one resident model process, like the Mac `ModelHost`: `whisper-server` for Whisper GGML models, `engine/parakeet_server.py` (sherpa-onnx, int8 Parakeet TDT 0.6B v3) for Parakeet. Both answer the same multipart request with `verbose_json`. One load or request runs at a time, so switching models never kills a request. Notes hold a lease; the idle policy unloads otherwise.
- Capture (`audio/capture.py`) runs `pw-record` (or `parec`) per source writing 16 kHz float32 to a pipe. System audio is the default sink captured with `stream.capture.sink`; a `<sink>.monitor` name is translated the same way. `WavWriter` writes on its own thread and refreshes the header about once a second.
- Notes (`notes.py`) record into `Audio/.recording-<id>` with `you.wav`, `others.wav`, `note.json` and a partial `transcript.json` every 30 s. Finishing names the folder after the title and converts to 48 kbit/s AAC M4A without overwriting. `recover()` turns leftover recording folders into library items on launch. A worker thread with a generation counter does all decoding, so discard and restart never let an old worker touch new state.
- Dictation (`dictation.py`) receives `press`/`release` from whisperdrop-ctl (D-Bus `org.gtk.Actions` on the app), or from the GlobalShortcuts portal (`shortcuts.PortalShortcut`, not used on Hyprland). Text goes through `insert.py`: wtype, ydotool, xdotool, or the clipboard.
- The Hyprland shortcut is a marked block written to `~/.config/hypr/bindings.lua` (or `hyprland.conf`) only after the user confirms in Preferences, with a `.whisperdrop-backup` copy. **Never create or remove binds at runtime with `hyprctl eval` or `hyprctl keyword`**: removing a runtime Lua bind segfaulted Hyprland 0.56.2 during development and killed the user's session.
- UI (`ui/`): `app.py` creates the shared objects once; `window.py` (library sidebar, search, date groups, drag and drop, paste a link), `home.py`, `job_page.py` (transcript, player, find, export), `note_page.py`, `new_note.py`, `preferences.py`, `guide.py`, `hud.py` (gtk4-layer-shell overlay, notification on GNOME). `Adw.ToolbarView` is final, so pages wrap one (`widgets.Page`).
- The player (`audio/player.py`) pipes ffmpeg into `pw-play` because GTK's GStreamer media backend and AAC plugins are often missing. `WHISPERDROP_PLAYBACK_TARGET` sends playback and dictation tones to another sink.
- `--data-dir` (or `WHISPERDROP_DATA_DIR`) isolates models, settings, history and saved files.

## Checking changes
- `python -m unittest discover -s tests` in `linux/` (55 tests; CI runs them in `.github/workflows/linux.yml`).
- Never play audio aloud, type into the user's windows, or record their microphone in tests. Use a null sink (`pactl load-module module-null-sink sink_name=…`), feed it with `pw-play --target`, capture `<sink>.monitor`, set `WHISPERDROP_PLAYBACK_TARGET`, and unload the module afterwards. `--verify-dictation CLIP` prints the dictated text instead of typing it.
- To see the UI without opening windows on the user's desktop, run `gtk4-broadwayd :5`, then the app with `GDK_BACKEND=broadway BROADWAY_DISPLAY=:5`, `WAYLAND_DISPLAY` unset, inside `dbus-run-session`, and open http://127.0.0.1:8085. Unset `WAYLAND_DISPLAY` before `dbus-run-session`, or activated portals connect to the real compositor.
- Do not run commands that change compositor state in the user's session. Read-only queries such as `hyprctl binds -j` are fine.

## Validation so far (2026-11-11, Omarchy, Hyprland 0.56.2, i7-11700, RX 6600)
- Parakeet v3 int8 through sherpa-onnx 2.0.1: load 1.4 s; a 3-minute Italian LibriVox recording in 9.5 s with model load; a 20-minute one in 53.8 s (2,310 words); the four sherpa test clips correct. whisper.cpp v1.9.4 built with Vulkan ran Whisper Base on the RX 6600 (11 s clip in 0.09 s once loaded). Switching between the two engines through the host worked.
- A streaming Italian note fed through a virtual microphone at normal speed with a pause: one sentence per paragraph, the 6 s played during the pause were not recorded, 72 s counted, M4A saved under the note title. The same through the Broadway UI with Stop and save.
- Click-to-play, highlight and find were checked in the UI, with playback sent to a null sink. The overlay was shown once on the real display through `--verify-dictation`; nothing was typed.
- Not checked: typing into other apps with wtype or ydotool (it would type into the user's focused window), the GlobalShortcuts portal on GNOME or KDE, X11, other distributions, and Whisper notes over a long session. A four-language test clip showed Parakeet dropping passages within one window; monolingual speech did not.
