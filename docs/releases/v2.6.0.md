WhisperDrop 2.6.0, build 10, integrates Draft's local writing tools and in-app updates into WhisperDrop. This candidate is prepared for local review and has not been published.

## App updates

- Check for updates from the app menu or Settings, General. Optional daily checks are off by default; installation requires confirmation.
- Updates and their feed are verified with Ed25519 signatures. Models, notes and settings remain outside the replaced bundle.
- Active work delays restart. The current main writing draft and suggestion are saved before quitting and restored on launch.
- A native local update between two isolated builds passed without an Apple Developer subscription. Altered archives and feeds were rejected. The public update feed will be available after the first signed release is published.
- Existing installations need one manual replacement with this bootstrap build. Further releases can update from the app. Details are in [in-app updates](../updates.md).

## Writing tools

- Writing tools open inside the existing main window, with the library sidebar and WhisperDrop styling. Returning to the library keeps the current draft and suggestion.
- Select text in another app and press Control + Option + D for a compact review panel. Change the shortcut in Settings, Writing.
- Fix grammar, make wording natural, adjust tone, rewrite, summarize, organize notes or make text concise. Edit preset names and instructions, or add actions, in Settings, Writing.
- Review and edit the suggestion, copy or export it. Replace is offered only for a verified source; focus, source and selection are checked again before pasting, followed by read-back.
- Temporary selection and dictation panels keep their own session and restore the main editor's unfinished work when dismissed.
- Style preferences and explicitly approved wording examples stay on this Mac. The Improve text macOS Service offers copyable results when a host app supports Services.

## Notes, transcripts and dictation

- Completed notes and file transcripts have a Writing menu. Summaries and revisions are saved as separate text versions. The original, subtitle timings and recordings remain available.
- Optional automatic summaries run after a note is saved. This is off by default. Capture interrupts text generation; interrupted note summaries wait until capture ends.
- The review panel appears after dictation by default, with an option to disable it. Dictating into the visible main writing editor keeps its field focused and uses the actions already present there.
- A panel cannot discard an unfinished draft or suggestion. Requests arriving during replacement cleanup wait for cleanup to finish.
- Long texts use the loaded tokenizer and include every section. Summaries combine section summaries; incomplete responses are rejected and original text is preserved.

## Local text models and context

Choose text models separately from speech models in Settings, Models, Text editing.

| Model | Download | Status |
| --- | ---: | --- |
| LFM2.5 2.6B QAD Q4_0 | 1.59 GB | Default |
| MiniCPM5 1B Q4_K_M | 688 MB | Experimental |

Automatic context uses the smallest suitable allocation, capped at 8K on Macs with up to 8 GB, 16K with up to 16 GB, and 32K above 16 GB. Manual 8K, 16K and 32K choices are available. Long texts are processed in sections when they exceed the working context. Context limits refer to the app's active allocation, not the models' advertised maximum.

Both models were compared at 8K, 16K and 32K on an M1 MacBook Air with 8 GB RAM. LFM produced better Italian results in these probes. MiniCPM used less memory and was faster, but changed facts, language and wording. Larger context did not resolve omitted responsibilities in long summaries. These are limited synthetic checks, not a general accuracy benchmark or a test on 16 GB hardware. Methods, timings and limits are in [writing tools verification](../writing-tools.md).

Review every suggestion. The final LFM probe passed its English and Italian grammar checks but introduced an Italian grammatical error in a separate natural-wording example.

Models load on demand and unload after five idle minutes. Downloads and imports are checked against pinned SHA-256 values. The bundled Metal runtime listens only on loopback with a per-process token. No weights, cloud services, accounts or API keys are bundled.

## Validation and distribution

The final full release suite passed 135 tests, with ten optional fixture-dependent checks skipped and zero failures. Before adding the updater, both debug and release passed 127 tests. Separate real-model checks covered both text models, 8K/16K/32K contexts, long summaries, resident speech models and cancellation. Native checks verified the integrated editor, retained drafts, saved versions and a complete update with signed archive/feed rejection controls; silent packaged transcriptions passed with Turbo and Parakeet. Physical hotkeys, live microphone capture and cross-app replacement still need a manual trial. Full methods and limits are recorded in [writing tools verification](../writing-tools.md) and [in-app updates](../updates.md).
