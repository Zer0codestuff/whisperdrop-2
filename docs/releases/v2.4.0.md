WhisperDrop 2.4.0 adds an experimental Parakeet engine, live text previews and saved-note renaming. Whisper Turbo Q5 remains the default.

## Changes

- Rename a saved note with **Rename…** beside its title or from its library context menu. Blank names are refused. The title survives reopening, and audio and transcript files retain their existing locations.
- Download Parakeet TDT 0.6B v3 with a 4-bit encoder, about 489 MB. It runs locally in a native Swift helper using MLX and supports 25 European languages, detected automatically. It ignores language hints and vocabulary lists. Unsupported language selections are refused before note or dictation capture starts.
- With Parakeet, **Live text** shows unconfirmed words while speaking. The dictation bar updates the latest 20 seconds about every 0.8 seconds; notes update about every 1.5 seconds while no completed chunk is waiting. Previews stop when recording ends or Live text is turned off.
- Parakeet file imports use pause-aligned windows of up to 35 seconds. Its file process is separate from the resident dictation and note model.
- Whisper dictation now keeps the full encoder window. The earlier shortened window returned unrelated words and duplicated sentences on real short clips. Short dictation still uses one segment to preserve sentence casing.

## Validation and limits

The [Parakeet evaluation](../parakeet-evaluation.md) records the datasets, raw experiment methods, results and follow-up validation.

On four public Italian talks with human subtitles, native file transcription scored 4.99% word error rate with Parakeet and 5.20% with Whisper Turbo Q5. End-to-end speed was 28.9x and 4.8x real time. These subtitles omit some words that were spoken, and the small accuracy difference does not establish a general advantage.

On 80 Italian and 80 English short clips through the app's dictation path, the corrected Whisper settings scored 2.30% and 3.11%, with median latency of 2.22 s and 3.40 s. Parakeet scored 2.72% and 3.35%, with median latency of 201 ms and 150 ms. Whisper still produced text for two of nine non-speech controls; Parakeet returned empty text for all nine.

The standard suite passed in debug and release: 92 tests passed and six optional model replays were skipped. Separate real-model checks verified four switches between Whisper and Parakeet.

Silent 60-second recording replays with live previews on and off preserved every sample at normal cadence, without dropped packets, and produced identical final transcripts. A run under competing benchmark and UI load dropped one 20 ms packet and displayed the capture warning. Capture under load is not guaranteed lossless. A separate normal-cadence replay with audio retention off saved the transcript and removed its temporary audio without dropped packets.

Native checks covered Models, Settings, model loading and unloading, an unsupported-language note, Italian file transcription, and the saved-note rename dialog. Automated rename checks cover restart persistence, notes without audio, duplicate names, unchanged saved files and failed writes. Live-microphone dictation and the live HUD were not checked in this pass. No older macOS system or independent reference for the user's lecture recordings was available.

The app grows to about 477 MB because it includes Parakeet and two MLX shader libraries. It requires no Python or cloud service at runtime.

## Install

Apple Silicon, macOS 14 or later. Quit the previous version and replace the app from the DMG. Models, notes and settings are stored separately from the application bundle.

This build has a verified ad hoc signature and is **not notarized**. No local code-signing identity was available during packaging. Gatekeeper may block a downloaded copy. If you choose to trust the build, use Apple's Open Anyway flow in System Settings, Privacy & Security. The DMG is a locally validated release candidate until publication is authorized.

The 207 MB DMG was mounted read-only and verified. Its app and all eight executable signatures passed, and all 23 packaged file hashes matched the final build.

Release assets include SHA256SUMS.txt and the unchanged FFmpeg 8.1.2 source archive. Runtime license notices are bundled in the app.
