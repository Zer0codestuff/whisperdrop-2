Recordings and transcripts now default to Documents/WhisperDrop, with separate Audio and Transcripts folders. This release also adds selective quiet-speech gain and checks for invented closing phrases and sustained repetition.

## Changes

- Open Settings directly from the main window.
- Choose a saved-files destination in Settings, General, Saved files. Existing managed files move with the library. Copies are verified before the originals are removed, and interrupted cleanup resumes after relaunch.
- Migrate earlier saved recordings and transcripts from Application Support automatically. Notes retain their original audio and export TXT, SRT and VTT transcripts.
- Enable Boost quiet audio by default for notes and imported files. Gain applies only when speech is quiet and sufficiently above the noise floor, with peak protection and a local voice detector. Original recordings and imported files stay unchanged.
- Check short Italian and English closing phrases against voice activity. Spoken phrases such as "Grazie" and "Ciao" are retained; unsupported closings in silence are removed.
- Retry sustained transcription loops once on original audio without previous text context. A candidate replaces the first result only when its repetition score improves. Unresolved passages keep a visible warning.

Turbo Q5 remains the default. Dictation, file imports, YouTube videos and playlists remain available. Transcription runs locally. Denoising is not enabled because it did not consistently improve the tested recordings.

## Validation and limits

70 automated tests passed in both debug and release. Three optional fixture-dependent tests skip in standard runs and were exercised separately. Eight real-model controls checked quiet spoken closings, silence, room noise and repeated sentences. A normal-cadence recording replay preserved all input samples within PCM16 quantization; a separate replay verified deletion when Keep audio is off.

The complete September 30 lecture replay reduced isolated closing phrases from ten to zero. Gain was skipped because the background noise was too high. Recognition errors and shorter repetitions remain, and there is no independent reference transcript for a lecture accuracy score. An accelerated 10x capture stress test dropped one packet and reported the loss.

The release app, disk image and nested signatures were checked. See [test methods and limits](https://github.com/Zer0codestuff/whisperdrop-2/blob/v2.2.0/docs/audio-storage-and-cleanup.md).

## Install

Apple Silicon, macOS 14 or later. Download the DMG, quit the old version, and copy WhisperDrop 2.app into Applications, replacing the previous copy. Models, notes and settings survive replacement. On first launch, earlier saved files move to Documents/WhisperDrop.

This release has a local code signature and is **not notarized**. Gatekeeper may block the first launch after a browser download. If you choose to trust this build, try opening it once and follow [Apple's Open Anyway instructions](https://support.apple.com/en-us/102445) in System Settings, Privacy & Security.

SHA256SUMS.txt contains release-asset checksums. FFmpeg-8.1.2-source.tar.xz contains the unmodified FFmpeg source used for this build; its configuration is in scripts/prepare-runtime.sh. Runtime license notices are bundled in the app and documented in the repository.
