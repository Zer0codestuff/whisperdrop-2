# WhisperDrop 2.6.1

This update makes notes safer to leave open and fixes microphone startup and recording recovery issues.

## Notes

- A recording pauses when your Mac sleeps or its lid closes. It stays paused until you choose Resume, and the note explains why it paused.
- A microphone that stops unexpectedly pauses the note and shows a warning. Dictation attempts to finish the captured speech and warns that it may be incomplete.
- Stop a note while microphone access is still pending without waiting for the permission prompt to finish.
- Audio and transcript folders, and kept recordings, use the note's title. Renaming a note also renames its managed files.
- Kept recordings use AAC M4A at 48 kbit/s. Older managed CAF recordings are converted after verification, with the originals moved to the Trash. If an M4A already exists at the destination, both files are kept and the app reports the problem.
- Preserve pending library renames if a conflicting file prevents recovery. A recording or conversion warning remains visible even when no speech was detected.

## Microphone and dictation

- Fix a startup crash after an input device changes to a different sample rate. The recording tap uses the current hardware format.
- Report microphone setup errors instead of closing the app. The fix applies to dictation and microphone notes.
- Settings, Dictation shows an Allow action when Input Monitoring is missing. Shortcut monitoring retries when the app becomes active after a permission change.

If the shortcut does nothing, allow WhisperDrop 2 in **System Settings > Privacy & Security > Input Monitoring**. Allow **Accessibility** to insert text into other apps and **Microphone** to record your voice. macOS can request these permissions again after an update. If monitoring still does not start, quit and reopen the app.

## Install

Apple Silicon, macOS 14 or later. From 2.6.0, use **WhisperDrop 2 > Check for Updates** or **Settings > General > App updates**. Earlier versions need the DMG once. Notes, settings and downloaded models stay outside the app bundle.

The app is locally signed and not notarized. A first downloaded copy may require **System Settings > Privacy & Security > Open Anyway**.

## Validation

The debug and release suites passed 167 tests each, with 11 optional checks skipped. An isolated native build was exercised with microphone capture, simulated sleep, manual resume, note saving and renaming, and a synthetic Italian file transcribed with Parakeet. Two-minute synthetic note replays at normal speed and at 8x reported no dropped packets. These are controlled tests, not a guarantee of accuracy or lossless capture. Physical lid closure, actual system sleep, a Bluetooth device switch and cross-app dictation still need verification.
