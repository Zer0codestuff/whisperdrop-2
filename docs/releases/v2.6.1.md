WhisperDrop 2.6.1 fixes a microphone startup crash and makes missing dictation permissions visible. It also includes the note naming and audio storage changes added after 2.6.0.

## Dictation and microphone

- Fix a crash when the input changes from a Bluetooth microphone to the built-in microphone with a different sample rate. The recording tap now uses the current hardware format.
- Recover from microphone setup errors instead of closing the app. The same correction applies to microphone notes.
- Settings, Dictation now shows an Allow action when Input Monitoring is missing. Shortcut monitoring retries when you return to the app after changing permissions.

If the shortcut does nothing, allow WhisperDrop 2 under **System Settings > Privacy & Security > Input Monitoring**. Allow **Accessibility** to insert text into other apps, and **Microphone** to record your voice. macOS can require these permissions again after replacing an app. If monitoring still does not start, quit and reopen WhisperDrop 2.

## Saved notes

- Audio and transcript folders, and kept recordings, use the note's title. Renaming a note renames its managed files too.
- Kept recordings are saved as AAC M4A at 48 kbit/s. Older recordings managed by the app are converted on launch after a frame-count check, with their CAF originals moved to the Trash. Transcript text stays unchanged.

## Install

Apple Silicon, macOS 14 or later. From 2.6.0, choose **WhisperDrop 2 > Check for Updates…** or **Settings > General > App updates**. Earlier versions need the DMG once. Notes, settings and downloaded models remain outside the app bundle.

The app is locally signed and not notarized. A first downloaded copy may need **System Settings > Privacy & Security > Open Anyway**.

Validation: debug and release each passed 146 tests, with eleven optional checks skipped and no failures. The signed app opened a microphone note, paused and resumed it, and transcribed a 122.5-second synthetic Italian file. A physical shortcut, cross-app insertion and a live Bluetooth switch still need user verification. See the [microphone diagnosis and test limits](https://github.com/Zer0codestuff/whisperdrop-2/blob/main/docs/microphone-startup.md).
